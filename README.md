# E-Learning Platform Purchase Analysis – MySQL Project
This project analyzes purchase data from an online e-learning platform using MySQL. The database contains three tables: learners, courses, and purchases. SQL joins, aggregation functions, and filtering techniques were used to analyze learner behavior, course popularity, and revenue trends.

## Project Overview
This project analyzes purchase data from an online e-learning platform using MySQL. The database contains three tables:

- learners
- courses
- purchases

SQL joins, aggregation functions, and filtering techniques were used to analyze learner behavior, course popularity, and revenue trends.

---

## Project Objective
The main objective of this project is to:
- Analyze learner purchasing behavior
- Identify top-performing courses and categories
- Understand revenue trends
- Generate business insights using SQL queries

---

## Database Tables
### 1. Learners
Contains learner details and information.

### 2. Courses
Contains course details including category and pricing.

### 3. Purchases
Contains learner purchase transactions and enrollment data.

---

## Descriptive Insights
- Analytics and Programming courses had the highest number of purchases.
- Some learners spent more on courses, showing higher engagement with the platform.
- Several learners purchased courses from multiple categories.
- Certain courses had low or no purchases.

---

## Diagnostic Insights
- Technical and career-oriented courses are more popular due to high industry demand.
- Learners interested in skill development purchased courses from multiple categories.
- Low-performing courses may have lower visibility or lower learner interest.

---

## Predictive Insights
- Demand for Analytics and Programming courses may continue increasing in the future.
- Personalized recommendations and bundle offers may increase multi-category purchases.
- Courses with low purchases may continue underperforming without proper promotion.

---

## Recommendations
- Focus marketing campaigns on top-performing categories such as Analytics and Programming.
- Introduce personalized course recommendations based on learner interests.
- Offer bundled discounts to encourage multi-category purchases.
- Improve promotion for low-performing courses.
- Monitor learner behavior regularly to identify future sales trends.

---

## Conclusion
This project demonstrates how MySQL can be used to analyze e-learning purchase data and generate business insights. The analysis helps understand learner behavior, course performance, and future opportunities for improving sales and learner engagement.
